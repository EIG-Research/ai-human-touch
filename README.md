# high-skill-worker-compete

This respository includes the data cited in "The economics of the human touch" by Adam Ozimek, published on Feburary X, 2026. Contact sarah@eig.org or jiaxin@eig.org with any questions. The microdata are sourced from IPUMS USA. See the IPUMS USA website for [occupation codebooks](https://usa.ipums.org/usa-action/variables/OCC#description_section) and guidence on which samples to select for historical decennial census years.
