# AI and the Human Touch

This respository includes the data cited in "AI and the Economics of the Human Touch" by Adam Ozimek, published on Feburary 9, 2026. Contact adam@eig.org or jiaxin@eig.org with any questions.

The microdata are sourced from IPUMS USA. See the IPUMS USA website for [occupation codebooks](https://usa.ipums.org/usa-action/variables/OCC#description_section) and guidence on which samples to select for historical decennial census years.
